# Templates

Starting points you can clone, deploy, and change.

| Template | What it does |
| --- | --- |
| [whatsapp-ai-agent](./whatsapp-ai-agent) | A WhatsApp agent on Vercel that answers with any model on OpenRouter. Connect the number, write the prompt, and read the conversations from the deployment itself. |
| [whatsapp-template-manager](./whatsapp-template-manager) | Write WhatsApp message templates, see them the way the phone will, and find out why one was rejected. Checks every rule Meta applies before you submit, and takes notes your AI agent acts on. |
